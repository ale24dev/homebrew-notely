# homebrew-notely

Tap de Homebrew para [Notely](https://github.com/ale24dev/notely), un gestor
de notas en Markdown para el menu bar de macOS.

## Instalación

```bash
brew tap ale24dev/notely
brew install --cask notely
```

## Actualizar

```bash
brew update
brew upgrade --cask notely
```

El `.dmg` de cada versión está firmado con un certificado Developer ID y
notarizado por Apple.
